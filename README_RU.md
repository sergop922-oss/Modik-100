# RandomDiseases: 100 Diseases Edition

Новый отдельный проект для Minecraft Forge 1.20.1 (Forge 47.2.0), Java 17.
Старый проект не изменяется.

## Сборка в GitHub Codespaces

Открой терминал в папке проекта и выполни:

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export PATH="$JAVA_HOME/bin:$PATH"
/tmp/gradle-8.8/bin/gradle build
```

Готовый JAR появится в `build/libs/`.

## Текущая основа

- 100 болезней в каталоге с четырьмя категориями и ценами лечения.
- Каждые 2 минуты сервер пытается выдать одну случайную болезнь.
- Уже имеющаяся болезнь не выпадает повторно; после лечения снова может выпасть.
- Клавиша O открывает меню лечения.
- Лечение покупается за алмазы: 60 / 45 / 35 / 20.
- Список активных болезней и таймер отображаются в левом верхнем углу.
- Болезни используют игровые эффекты Minecraft.

Это первая версия нового проекта. Некоторые сложные визуальные механики (например, половина экрана и блокировка отдельных частей тела) будут добавляться и проверяться отдельно, чтобы не ломать сборку.
